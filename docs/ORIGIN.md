# 缘起：从「人才库」到 EvidenceGate

本项目并非另起炉灶，而是在原有设想之上，对适用范围作了一次重新界定。三点说明如下。

- **范围层面**：原设计聚焦人才库单一场景，机制可复用，但数据契约与语义难以迁移至同类的「材料—判断」场合。
- **实例层面**：作为以可核验为立身的系统，其结论尚缺可供反复比对的可信案例作为支撑；在此条件下加深功能，收益有限。
- **处置方式**：将原场景降为一个 profile 并完整保留，把证据脊柱升为系统主体，使系统得以在更宽的场景中接受真实检验。

原有的人才筛选功能——岗位、候选人、正反辩论、三评委与回测对齐——均予保留，可从控制台按原路径进入。
